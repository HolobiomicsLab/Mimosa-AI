e25_creed — why E18's pairwise scripts scored 0.480

E25 asks why E18's per-pair comparison scripts scored 0.480 on directly judged pairs. Phase 1 depth-classifies all 599 E18 scripts into tier 0 EXISTENCE/SCHEMA, tier 1 VALUE-PARSING and tier 2 DISTRIBUTIONAL/RELATIONAL, then measures within-task pairs-correct conditional on the deciding tier. Phase 2 re-runs the comparator on the 77 rescued E18 ties with four pre-registered variants — V1 depth contract, V2 internal ladder, V3 dual-score, V4 relational — then a full-arena arm.

The E25 phase 2 pilot was still running while this clone was built, and the V3 arm was still writing rows when this page was last checked (the judgments file held 131 rows at the first read and 219 at the snapshot below), so every phase 2 count here is a dated snapshot; the phase 1 numbers are final.

5 · experiments_verifiers/results/E25_creED_autopsy_2026-09-25.md line 37, the whole verdict line; the same text is E25_creED_autopsy_2026-09-25.json line 1863

**NEITHER shallow checks NOR proven pairwise blindness — the pre-registered hypothesis is REFUTED, and the defect that remains is a fixable DECISION-CONTRACT defect.** (1) E18's scripts were NOT shallow: after rule+LLM classification under the assignment's definitions, 128/130 decided contrast pairs (98%) were decided by VALUE-PARSING (row counts, domain fractions, extracted numbers); EXISTENCE/SCHEMA alone decided 1 pair and DISTRIBUTIONAL/RELATIONAL 1. Depth does not separate accuracy: VALUE-PARSING-decided pairs score 0.4766 [0.384,0.540] (decisive-only 0.442 — BELOW chance); no depth tier reaches the pre-registered 0.65 bar. 'If deep-decided pairs are accurate, the prompt was the problem' therefore resolves against the shallowness story: the checks were already deep and still wrong. (2) The wrongness is STRUCTURED, and every structure is a contract defect the retrial targets: (a) boolean/schema composite collapse — schema/boolean-compliance 0.462 (n=39) plus generic boolean composites 0.425 (n=40): scripts sum +1 flags (header_ok, token present, rowcount==expected) and let the flag TOTAL decide — E19b's H3 boolean-collapse transplanted into the pairwise contract; (b) criterion instability — 8/9 label-swap winner flips re-derived a DIFFERENT deciding metric on regeneration (max_abs delta-rho vs script-token checklist; max_z compared at print precision vs output-path presence; byte-size with longer-wins vs shorter-wins inverted), so every fresh script is a fresh coin; (c) tie collapse on degenerate equality — 261/295 ties are literal equalities of non-discriminating quantities and the contract imposed no escalation duty; (d) genuinely graded/relational evidence is rare but not wrong (graded/distributional 0.75 on n=4; value-domain 0.545 with 91% ties; row-count 0.546). (3) Architecture verdict DEFERRED, not acquitted: the same judge model under E19's per-workspace graded contract reaches 0.667 on the same arena, so the artifacts carry the signal. What the per-pair winner-emission contract lacks is a fixed rubric, graded quantities, an escalation ladder and relational checks — exactly V1/V2/V3/V4. If V3 (symmetric dual-score emission) recovers E19-level ranking while winner-emission variants do not, the defect was the emission contract; if nothing recovers, pairwise visibility itself is implicated.
