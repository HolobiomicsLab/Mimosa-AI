e13_umap.py

Arm-a figure script of E13: it re-projects the cached claim embeddings into 2-D with UMAP and colors each claim by its learned L3 weight w(c)=beta·phi(c). It runs offline, after e13_l3_extreme.py stage a, with the umap-learn overlay. Zero API calls; it writes one PNG and one statistics block into the shared E13 results JSON.

Master diagram — what the file does, left to right

Diagram 1 — one function drives five steps: load, refit, project, plot twice, quantify. Every step name is a real call made inside main() (e13_umap.py lines 25–85).

Data flow — what goes in, what comes out

Diagram 2 — the script is a leaf consumer: it reads two frozen caches and appends one stats block plus one PNG. Path constants live in e13_common.py (lines 22–25).

Control flow — two loops and one clipping rule

Diagram 3 — the only decisions are the color clip (line 43) and which 25 claims to label (lines 47–52); the same nearest-neighbour test is run twice (lines 71–80).
