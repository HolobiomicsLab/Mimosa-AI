e5_common — E5 shared loading and metrics

E5 asked whether the LLM's self-reported claim importance (1–10) can be replaced by weights learned from claims × outcomes. This page covers e5_common.py, the shared library that loads the frozen claims, joins each claim name to its rubric source letter, and computes the metric block. Every number in the E5 results file is labelled “my computation”.
