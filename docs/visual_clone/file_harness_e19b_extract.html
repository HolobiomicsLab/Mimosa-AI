e19b_extract.py

This file builds the paid E19b artifacts: extraction v2 claims, V4 scorer scripts, score cells and refinement rounds, all under a $10 cap. It runs six command-line subcommands and appends every step to resumable JSONL ledgers. It is the largest file of the batch at 891 lines.
