workflow_runner.py

WorkflowRunner writes a Python script to <temp_dir>/<execution_id>.py and runs it as a host subprocess. It resolves the interpreter on PATH, installs dependencies into a managed venv, streams stdout through a pseudo-terminal, and enforces the timeout. It is the only subprocess engine in the repo: the orchestrator uses it for generated workflows, the verifiers use it for scorer scripts.
