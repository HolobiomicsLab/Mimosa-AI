Variation: how a genotype changes

VariationEngine turns a parent genotype plus verifier feedback into a prompt for the workflow LLM. Mutation edits one parent; crossover recombines two or more. The new genotype is embedded so the QD archive can read how different it is.

Mutation rules written into the prompt (variation_engine.py:448-453): follow the directive, add or remove at most one agent, use at most agent_budget agents, keep the topology unless the directive says otherwise, keep 90% of the previous code, and edit no prompt outside the directive scope.

The gradient reaches the prompt as <directive>...</directive> only. The raw verifier diagnosis and agent answers are consumed by the directive LLM, not by the workflow LLM (variation_engine.py:426-446).

Gradient text is cleaned before use: underscores become spaces, the block is cut at 2048 characters, and an empty gradient falls back to the run stderr, then to a fixed failure sentence (variation_engine.py:402-407). Crossover falls back to the last 1024 characters of stderr per parent (variation_engine.py:489).

Gotcha: crossover builds an answers field per parent but never prints it; the prompt shows code and gradient only (variation_engine.py:490 vs :505-512).

Comment: the code states MiniLM truncates at 256 word-pieces, about 950 characters of code (3.7 chars/token measured on real genotypes) (genotype_embedding.py:85-86). Whole-workflow sources run 1,000-12,000 characters, so the 900-character cap keeps every agent prompt inside the budget.

Width 384 is not hardcoded: it comes from the model cache. I read the local cache config as 384 hidden size, e.g. ~/.cache/huggingface/hub/models--sentence-transformers--all-MiniLM-L6-v2/<snapshot>/config.json (my observation, not a repo file).

The retired structural descriptor had 4 named fields, [n_agents, n_edges, n_branches, prompt_chars] per docs/concepts/evolution-engine.md:139; a grep over sources/*.py finds no code that computes them now.

Where this differs from a classic GA

There is no gene string, no fixed mutation rate, and no generation-wide replacement: the directive LLM chooses the magnitude from a plain score block, and variation edits free Python text.
