Human mode and the TTS hook

Human mode replaces the LLM decision step with an operator menu: --manual loops over MCP servers and tools until Ctrl+C. The text-to-speech hook is a separate optional path: Planner.run_attempts speaks task events through TTSService. Neither path is read by the verifier.

Planner.__init__(enable_tts=True) default builds the service; no caller passes enable_tts=False. Value conversion: speed must be positive. Audio rate is fixed at 24000 Hz in _save_audio. Voices: af_kore, zf_xiaobei and 19 more in KokoroTTSEngine.VOICES; voice_index is clamped to the list. JapaneseTextProcessor and FrenchTextProcessor delegate to the English one.

Both paths are optional side branches: no verifier claim, scorer or reward reads them, so they never change VER, SR or CBS.

Amber: kokoro and soundfile are not in pyproject.toml, so on a fresh install KokoroTTSEngine.is_available() returns False and TTSService.speak returns None.

Amber: HumanMode.discover_tools and HumanMode.execute_tool build the URL as http://{mcp.address}:{mcp.port}/mcp and ignore MCP.transport, so an SSE server is unreachable from human mode.
