code_features.py

QD-facing shim: it turns workflow source code into the unit-norm embedding used as the novelty descriptor. The single function genotype_embedding_descriptor (line 10) calls embed_genotype from sources/core/genotype_embedding.py and converts the NumPy array to a plain list[float]. It runs once per candidate inside SelectionPressure; the novelty rule itself lives in selection.py.
