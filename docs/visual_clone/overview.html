Mimosa-AI, whole system

For each task Mimosa synthesizes a workflow as plain Python, runs it in a sandbox, verifies the run with the verifier that verifier_kind selects (default: hybrid temporal-ladder), and evolves the workflow across generations. Five layers carry that loop; the verifier's gradient text steers the next mutation. Start here, then open a flow page or an area page.
