e19_bt_eval — decisive pairs and readouts

This experiment asks whether the E19 claim scores rank generations better than E15, E18, the recorded reward, and uniform. The script converts the score ledger into decisive pairwise winners, fits a Bradley-Terry table, and for the first time in the E19 chain reads the benchmark labels. It writes the E19 file of record and one gradient text per generation.
