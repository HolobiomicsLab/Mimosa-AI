layers.py

This file defines the evidence-layer interface and its three layers: ClaimsEvidenceLayer turns one workspace into (claim_id, score) pairs, VisualEvidenceLayer scores figures for figure tasks, and ExecutionGateLayer caps the reward from re-execution status. It runs once per evaluated generation, called from evaluator.py. Package context is on mod_evaluators_hybrid_verifier.html.

Diagram 1b — the two E35 layers the file adds beyond the claims pipeline. VisualEvidenceLayer is armed only for figure tasks and freezes its claims once; ExecutionGateLayer only caps the reward through its gate hook.

TaskRegistry object in memory. Persistence is registry.save(), called once per evaluation at evaluator.py:644. gen_parallelism is a constructor argument of the evaluator, not a config key (evaluator.py:153, 220); it sets the ThreadPoolExecutor width (585-586).
