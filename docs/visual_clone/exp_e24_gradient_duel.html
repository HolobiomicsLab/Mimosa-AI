e24_gradient_duel — five-way gradient duel

Does a gradient built only from measured execution facts steer the judge as well as text-based gradients? The script writes one measured-facts gradient per frozen generation, then runs a five-way duel behind one identical judge prompt. It compares E24 against E19, E18, E15 and the production verifier on 123 paired generations.

A gradient file says only measured execution facts: re-execution status, divergence counters, and the holdout metric against the group field. No SR, VER or reward appears in the text. The judge prompt is the E16v2 instrument (e16_gradient_audit.py::judge_messages, L498); only the gradient text differs between sides.

Amber: the e19, e18, e15 and ver sides are served from the E16 judge cache (identical messages, zero new calls). Only the 123 E24 calls are fresh, so the comparison is a text swap inside one fixed prompt.

Why it matters: if the E24 text scores highest on hallucination but lowest on gold-relevance, the difference is a framing difference in the feedback, not a factual error in it.
