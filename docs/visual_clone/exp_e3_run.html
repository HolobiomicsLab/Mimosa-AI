e3_run — Design A pilot: two judge families

E3 asked whether two LLM families from different labs, each writing and answering its own binary checklist, rank benchmark artifacts better than the recorded verifier reward. e3_run.py runs that design: it samples a 20-row pilot, scores both families, corrupts ten workspaces as a sabotage control, and writes the pilot metrics. It also holds the report code that later scripts reuse.
