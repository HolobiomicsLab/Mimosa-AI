e13_common.py

This file is the shared machinery of experiment E13: it loads the three claim universes, builds the L3 and L3b feature matrices, runs task-level leave-one-task-out logistic folds with an inner C grid, and reports paired per-task statistics. It also indexes run_notes/ by uuid and reads and writes the E13 result JSON. It has no main() and no CLI: it runs only when one of the two E13 scripts imports it.
