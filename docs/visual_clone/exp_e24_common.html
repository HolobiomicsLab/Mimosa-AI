e24_common — shared E24 plumbing

E24 asks whether re-executing a delivered workflow, and scoring generalization on a holdout the verifier owns, ranks generations better than artifact inspection. This module is the shared base of the four E24 scripts: paths, one LLM call, append-only ledgers, plan loading, and two metrics. It has no entry point of its own.
