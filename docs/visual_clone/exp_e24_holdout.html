e24_holdout — Phase 2, verifier-owned holdout

Can a verifier score generalization without touching the benchmark's gold? This script splits each admissible group's own labeled train file 80/20, strips the labels from the held-out 20%, re-executes the delivered script, and scores its predictions against labels kept only in the verifier's key file. The pilot gate returned PROCEED with 3 of 5 groups computable.
