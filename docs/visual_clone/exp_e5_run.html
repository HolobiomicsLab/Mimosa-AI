e5_run — the learned-importance ladder

E5 asked whether claim weights learned from claims × outcomes can replace the LLM's self-reported 1–10 importance in the verifier reward. e5_run.py fits seven learned variants on four ladder levels (L0.5–L3), from a source-letter model up to MiniLM embeddings, scores them with task-level leave-one-task-out, and writes one JSON plus one MD. The recorded answer is a conditional pass: the top rung wins between tasks (auc_sr 0.753 against 0.640 for the recomputed reward) and ties it within tasks.
