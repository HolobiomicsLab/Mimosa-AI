claims_pca_3d.py

This script draws the claim-text space in three dimensions: it embeds every unique claim name with MiniLM, projects the vectors to three PCA components, and writes one interactive plotly HTML plus a CSV of the coordinates. Each point is one (task, claim) pair and the colour encodes the task, so a claim shared by several tasks lands on the same coordinates. It runs offline from the command line, needs plotly, and nothing in the repository imports it.
