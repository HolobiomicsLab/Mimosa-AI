e3_run2 — compliant rerun of Design A

E3's first judge pair used glm-5.3, which broke the operator rule that judges must be cheap flash models. e3_run2.py rescores the frame with qwen3.7-flash and deepseek-v4.1-flash, reuses the deepseek answers verbatim from the old state, and aborts if the cost projection passes $1. Its report stage never ran, so no metrics file exists; the state file is the only evidence.
