e19c_ratchet.py

Runs the production hybrid_verifier package over the frozen E14 arena: one digest and one ladder extraction per group, then one policy scorer per claim re-executed on every generation's workspace. It owns only the LLM transport and the sandboxed subprocess execution; prompts, validators and the registry come from the production modules. It runs offline as a CLI (python e19c_ratchet.py run|rescore|status|verify), not from main.py.
