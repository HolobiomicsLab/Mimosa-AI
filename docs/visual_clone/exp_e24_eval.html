e24_eval — Phase 3, confirmatory evaluation

Does an execution-grounded score rank generations better than artifact inspection? This script reads the E24 ledgers once, composes one score per generation, and runs the same pairs-correct and M2 readouts as E15, E18 and E19. It writes the results JSON and the results markdown.
