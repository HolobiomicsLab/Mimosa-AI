e18_bt_eval — does LLM-written code rank generations better?

In E18 the judge writes deterministic Python comparison code from the two candidates' artifacts, and the script's own output picks the winner. This script is the evaluation half: it fits per-group Bradley–Terry strengths from the scripted verdicts, then compares them with E15 preference judgments and with the recorded verifier reward. It also writes one gradient text per generation; the producer channel is on exp_e18_scripted_bt.html and the three-way duel on exp_e18_gradient_duel.html.
