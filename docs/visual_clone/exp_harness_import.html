harness_import.py — the shim nobody imports

This module is the designed fix for the harness's import problem: seven lines that put the harness directory on sys.path so its modules can import each other whether they run as scripts or as a package. The question this experiment answered is whether that fix is the one in use. It is not: no .py file in the working tree imports the module, and 40 of the 53 harness scripts insert the same path themselves.

full module body and import order
"""Shim so harness modules import each other whether run as scripts or as packages."""
import sys
from pathlib import Path

_here = Path(__file__).resolve().parent
if str(_here) not in sys.path:
    sys.path.insert(0, str(_here))

That is the complete file (7 lines, quoted from experiments_verifiers/harness/harness_import.py). The guard if str(_here) not in sys.path keeps the import idempotent. The inserted path is experiments_verifiers/harness, which is what the sibling scripts need for import e15_bt_eval style imports.
