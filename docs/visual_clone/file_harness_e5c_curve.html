e5c_curve.py

This script measures how few tasks the E5 rung L3 still generalizes from: task-level random splits at nine training fractions F from 0.10 to 0.90, 40 seeds each. It reuses the e5b_splits.py helpers for the splits, the C grid and the paired statistics, then derives a minimum viable F, a saturation point and a log2 reconciliation. It writes a JSON, a Markdown digest and an SVG plus a PNG plot; run it with uv run python experiments_verifiers/harness/e5c_curve.py (L12).

Diagram 3 — the fraction loop and the three decision rules

Diagram 3 — 6 boxes. Each seed is skipped when the train side (L62) or the test side (L65) holds one class, or when the AUC comes back nan (L70); the seed number is written into rec["skipped_seeds"] (L59) instead of being lost. min_viable_f (L113) returns the first block, in ascending F order, where the paired win-rate against every baseline is at least 0.60, the mean dAUC is above 0, and the t-test p is below 0.05 (L119–120). saturation_f (L128) returns the first F whose L3 mean is within 0.01 of the F=0.9 mean (L132).
