e19b_gradient_duel.py

This is the smallest file of the batch: a five-way gradient duel on 123 paired generations. It swaps the E19b V5 gradient text into the E16 judge prompt and judges four baseline channels plus the verifier channel, then bootstraps the paired differences. Only the E19b side needs fresh judge calls.
