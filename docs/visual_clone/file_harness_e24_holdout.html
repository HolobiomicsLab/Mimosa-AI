e24_holdout.py

This file is E24 Phase 2: the verifier builds its own labeled evaluation from the workspace's own train data, with zero gold access. It cuts one fixed 80/20 split per admissible group (seed 20260924), rewrites the held-out 20% as the test file with labels stripped, re-executes the delivered script on that swapped copy, and scores the fresh predictions against the labels it kept. Two commands: split then run (--pilot redacts every metric value).
