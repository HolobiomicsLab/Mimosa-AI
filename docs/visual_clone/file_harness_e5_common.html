e5_common.py

This file is the shared data and metric library of the E5 experiment line: it loads the frozen claim verdicts, joins rubric provenance to tasks, and computes the AUC, Kendall tau, within-task and bootstrap numbers. It has no main() and writes nothing, so it runs only when a caller imports it — ten files do. The frozen inputs under experiments_verifiers/data/ are read-only (docstring L1–L4).
