harness_import.py

This 7-line file is a shim: on import it puts its own directory, experiments_verifiers/harness/, at the front of sys.path so the harness modules can import each other whether they run as scripts or as a package. It defines no function and no class, and nothing in the repository imports it (grep result below), so its body runs only if a module imports it. The same three lines are hand-copied in 40 of the 53 Python files in that directory.

the whole file
"""Shim so harness modules import each other whether run as scripts or as packages."""
import sys
from pathlib import Path

_here = Path(__file__).resolve().parent
if str(_here) not in sys.path:
    sys.path.insert(0, str(_here))
