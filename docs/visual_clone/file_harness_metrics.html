metrics.py

This file is the section-0 metric library of the verifier-search harness: it turns one score vector plus SR/VER labels into AUC, Brier, Kendall tau, within-task ranking accuracy, an exact McNemar test and two task-cluster bootstraps. It has no main() and reads no config, file or state, so it runs only when a caller imports it. Two scripts do that, run_e1.py and run_e2.py, and every number they publish is labelled "my computation".
