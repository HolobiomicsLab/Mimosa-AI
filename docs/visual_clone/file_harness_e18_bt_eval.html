e18_bt_eval.py

This file is the evaluation half of E18: it reads the frozen E14 pair plan and the written E18 verdict ledger, fits one Bradley-Terry strength per generation, then compares that ranking with the E15 preference ranking and the recorded verifier reward. It also writes one execution-grounded gradient text per generation under results/E18_bt_gradients/ (L135, L187). It runs as uv run python experiments_verifiers/harness/e18_bt_eval.py and re-uses the Bradley-Terry fit and paired statistics of e15_bt_eval.py, imported as E15E (L36).

Diagram 3 — the logic: the BT match rule and the guard on the per-group rank

Diagram 3 — 12 boxes. The Q2 rule is the same shape: a mean Spearman above 0.6 against the E15 ranking is called convergent, otherwise a different channel (L564–L566). The BT fit re-uses e15_bt_eval.bt_fit_weighted with ridge 1.0 (protocol string L430).
