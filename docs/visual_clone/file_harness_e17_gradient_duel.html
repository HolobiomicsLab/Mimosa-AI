e17_gradient_duel.py

This script judges the same generation twice: once with the E15 preference gradient text and once with the verifier's textual_gradient.txt, using one identical E16 judge prompt, then compares the two judgments per generation. It runs as uv run python experiments_verifiers/harness/e17_gradient_duel.py and writes one verdict to experiments_verifiers/results/E17_gradient_duel_2026-09-23.json plus a markdown copy. It imports e16_gradient_audit.py as E16 (L32) and adds no new instrument of its own.

Diagram 1 — 8 boxes. build_pairs keeps only generations that have both texts; judge_bt replaces the gradient block of the E16 prompt and nothing else (L68–L69), while the verifier side calls E16.judge_item on the same population item (L91).
