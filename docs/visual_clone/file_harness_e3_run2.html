e3_run2.py

This is the E3 finisher: it takes over an interrupted run with a cheaper judge pair, qwen3.7-flash plus deepseek-v4.1-flash, and runs three stages: score, sabotage, report. It keeps the stored DeepSeek replies of the 52 legacy rows verbatim and only re-scores them with Qwen L163. A spend gate stops the scale-up when the projection passes one dollar L182–L204.
