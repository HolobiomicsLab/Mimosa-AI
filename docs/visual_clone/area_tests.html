how I counted (and what the count misses)

Method: python ast pass over every .py file for imports, path literals and def test_* names, plus grep -n to confirm each named symbol. lines is the newline count (wc -l).

Five files do not import their target; they load it by path so that sources/core/__init__.py (litellm, sentence-transformers) never runs: archive_projection_test.py:23, lineage_goal_filter_test.py:19, planner_json_extraction_test.py:29, selection_test.py:16, smolagent_factory_logprobs_test.py:71.

test funcs counts functions, not collected tests: smolagent_factory_logprobs_test.py uses @pytest.mark.parametrize, so pytest collects more items than this column shows.

Per-file line split of the biggest files: hybrid_verifier_test.py 1270 lines, astra_exporter_test.py 649, verifier_recovery_test.py 415.

Why it matters: the whole suite is offline and needs no API key, MCP server or Toolomics (AGENTS.md:161-165), so it can run in CI without secrets.
