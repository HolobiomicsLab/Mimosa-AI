e15_bt_eval — does the preference ranking carry the within-task axis?

E15 asked whether pairwise preference judgments rank generations by benchmark success better than the recorded reward. This script fits one Bradley-Terry model per task group from the 667 frozen verdicts, writes a preference gradient per generation, and only then reads the SR labels. Its one-sentence answer was NO DECISIVE GAIN at this power.
