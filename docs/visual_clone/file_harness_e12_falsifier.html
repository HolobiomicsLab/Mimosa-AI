e12_falsifier.py

This script is experiment E12, the pre-registered falsifier for instability-discounted claim weights: it orders each task's generations by the engine's own evolution order, measures per-claim flip rates inside only the first k generations, freezes w(c) = base(c) * (1 - flip_rate), and replays the E9 picker over every generation. It runs offline with no API key, reuses e5_common and e9_deployment, and writes one JSON and one Markdown file under results/. It has no CLI arguments and no importer: the documented way to run it is uv run python experiments_verifiers/harness/e12_falsifier.py.
