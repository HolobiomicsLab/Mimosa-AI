registry.py

This file stores per-task verifier state in one JSON file: the claim set with cached scorer scripts, every generation's score vector, the union inventory and the refinement counters. It runs on every evaluation, loaded and saved by evaluator.py. Package context is on mod_evaluators_hybrid_verifier.html.

Why it matters: the same claim set and cached scorer scripts grade every generation, so a win-rate comparison compares like with like.

Naming note: the docstring calls the persistence "atomic" (L123), but save writes in place with write_text (137) and does not use a temporary file plus rename. A crash mid-write can leave a truncated file; load then warns and starts from an empty state (83-85).
