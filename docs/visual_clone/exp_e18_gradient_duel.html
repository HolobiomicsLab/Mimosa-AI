e18_gradient_duel — three-way gradient duel

This experiment asked which feedback text points a mutation at the benchmark gold most often. It judged three gradients with one instrument: the verifier rubric, the E15 preference transcript, and the E18 scripted transcript. Only the gradient text differed between the three judging calls.
