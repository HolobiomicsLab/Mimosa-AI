e19_gradient_duel — four-way feedback comparison

This experiment asks which gradient text points a judge at the gold more often: the E19 transcript, the E18 scripted feedback, the E15 preference text, or the verifier rubric. It reuses the validated E16 instrument and changes only the gradient text, so the judge prompt is identical across all four sides. It writes a 123-row paired table and a verdict; the E15, E18 and verifier sides are cache hits.

Design — four gradient texts, one judge instrument

Diagram 4 — 11 boxes. build_quads (L37) keeps only generation triples where all four gradient texts exist; judge_with_text (L71) replaces the gradient text inside the E16 prompt and sends it through the shared cache (E16._llm, L75); paired (L112) computes the cluster bootstrap over task groups. The captures at L141–150 build the side means; the verdict logic is at L182–203.
