Modules and prompts

Two Python templates and ten Markdown prompts are read from disk and spliced into every generated workflow script. The workflow factory reads them, the assembly step pastes them into one module, and the runner executes that module in a subprocess. No page describes the templates line by line.

File size of each prompt

Bar chart - the ten prompts range from 6.1 kB (workflow_v10.md) to 15.9 kB (smolagent_sys_prompt.md). Numbers are my computation from os.path.getsize.

Pattern of the prompt files

All ten are plain Markdown: no YAML front matter, first line is a single # title, then ## sections. Length runs from 94 to 429 lines (wc -l; no file ends with a newline). Lines that start with #, code comments included, range from 7 to 65 (my computation).
