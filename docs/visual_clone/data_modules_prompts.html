Modules and prompts

Two Python templates and ten Markdown prompts are read from disk and spliced into every generated workflow script. The workflow factory reads them, the assembly step pastes them into one module, and the runner executes that module in a subprocess. No page describes the templates line by line.

File size of each prompt

Bar chart - the ten prompts range from 6.1 kB (workflow_v10.md) to 15.9 kB (smolagent_sys_prompt.md). Numbers are my computation from os.path.getsize.

Pattern of the prompt files

All ten are plain Markdown: no YAML front matter, first line is a single # title, then ## sections. Length runs from 95 to 429 lines. Heading count ranges from 7 to 65.

workflow_v15.md

Starts with execution context and router reference, then a section that lets the LLM design its own routers with a stated contract.

333 lines · 21 headings · git log: added by commit 80b386e "feat: new v15 prompt + sandbox fix"

workflow_v9.md

Oldest style: architecture principles first, then a long catalogue of workflow patterns for scientific computing.

429 lines · 65 headings · largest heading count of the set

smolagent_sys_prompt.md

Tells one agent how to work: tool use versus Python, execution boundaries, output format, core patterns.

407 lines · 24 headings · loaded as SYSTEM_PROMPT, then applied by SmolAgentFactory.override_system_prompt
