e19c_gradient_duel.py

This experiment script joins the E19c production gradients to the E16 population, then judges seven feedback channels for the same generations with one fixed judge prompt. It runs only from the command line, behind the guard at L245. It writes one JSON and one markdown report under experiments_verifiers/results/.
