run_e2 — E2 static grounding

E2 asked whether grader-free deterministic checks alone can predict VER strongly and SR at least as well as the LLM-judged reward. run_e2.py scores 135 frozen workspaces under two check sets and runs a sabotage control on copies. The extended check set reaches AUC_ver 0.792, below the 0.85 gate; the attributable-failure subset reaches 0.953.
