workflow_info.py

WorkflowInfo is a read-only accessor for the artefacts of one workflow folder. It loads state_result.json, the genotype script, evaluation.txt and textual_gradient.txt when a property is first read. Writer of the folder: the workflow runner; readers: parent selection, the planner, variation and the evaluators.
