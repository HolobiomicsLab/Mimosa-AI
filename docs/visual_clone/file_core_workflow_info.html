workflow_info.py

WorkflowInfo is a read-only accessor for the artefacts of one workflow folder. It loads state_result.json, the genotype script, evaluation.txt and textual_gradient.txt when a property is first read. Since 4020790 it also tells callers if a reward is a fallback, and a module function tells if a folder was graded by the gold (oracle) verifier.

Main diagram - one folder, read as properties

Diagram 1 - 11 boxes. Entry point: WorkflowInfo.__init__ (sources/core/workflow_info.py:49) binds paths and reads nothing; every value crosses a property that reads a file on first use. Solid arrows are calls, dashed arrows are file reads; the self.goal fallback of original_task is written in its box, not drawn. The ORACLE box is module level: workflow_selection.py and gold_feedback/evaluator.py call it.

calculate_overall_score and reward_is_fallback both go through _selected_evaluation, so the score and its fallback flag always come from the same evaluation block.
