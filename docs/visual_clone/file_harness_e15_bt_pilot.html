e15_bt_pilot.py

The live judging engine of the E15 preference pilot: it walks the pair plan written by e14_bt_enabler.py and asks two OpenRouter judges which of two workspaces delivered more. Every pair is judged in both listed orders, a disagreement triggers one third vote, and each call is appended to a cost ledger. It is resumable and stops when a cost cap is reached.

The docstring states the gold-hygiene rule: prompts hold only the task goal plus inventories, previews and images; SR, VER and reward are never placed in a prompt (lines 8–9).

Reasoning is switched off for both judges with extra_body (line 156), and the docstring records why: as reasoners they would exhaust max_tokens before emitting JSON (lines 149–151). This is a deliberate deviation from the models' defaults.
