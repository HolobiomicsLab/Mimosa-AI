gold_feedback — ORACLE verifier control

Six files wrap the hybrid verifier with the benchmark grader, selected by --verifier_kind gold. The grader’s VER/SR messages replace the textual gradient; with gold_feedback_reward the grader also gives the reward. This mode reads the benchmark gold, so its scores must never be reported.
