Interactive front ends

Three wizards cover the terminal: OnboardCLI runs when no mode flag is given, EvaluationCLI when --evaluation_cli is given, and MemoryChatCLI when --memory_cli is given. All three are chosen in main.py::main before the argument-driven path starts. Two shared modules draw the output: theme.py for the wizards, pretty_print.py for the rest of the codebase.

The three CLIs

sources/cli/onboard_cli.py

Setup wizard when no mode flag is given: keys, workspace, models, MCP scan, objective refinement, then planner or evolution engine.

1 611 lines · class: OnboardCLI · TOTAL_STEPS = 9 · called by main.py::main

the nine steps (OnboardCLI.run)
1  API Key Check              _check_api_keys
2  Configuration              _load_config
   workspace resolve          _verify_workspace_dir
3  LLM Model Selection        _choose_models
4  Toolomics MCP Connectivity _check_toolomics
5  Workspace Setup            _setup_workspace_files
6  Your Research Objective    _collect_objective
7  Clarification & Refinement _clarify_and_refine
8  Mode Selection (Goal/Task) _classify_and_confirm
9  Options & Launch           _collect_options, _launch

Reads os.getenv for 6 API keys; writes the env file via paths.user_env_file(). Persists with Config.dump() to config_default.json (installed runs: ~/.config/mimosa/config.json, _persisted_config_path). Objectives go to _save_objective_to_history.

launch and failure paths
OnboardCLI._launch()          -> config.validate_paths(), exit 1 on AssertionError
OnboardCLI._launch_goal()     -> Planner.start_planner(goal, judge=True)
OnboardCLI._launch_task()     -> EvolutionEngine.start_workflow_evolution(goal, judge=True, enable_evolution=self._learn)
OnboardCLI._verify_workspace_dir() raises no skip: path must contain "toolomics"
_clarify_and_refine()         max_clarification_rounds = 5, then manual fallback
_check_toolomics()            retries every 15 s until one MCP answers, or user types "skip"

sources/cli/evaluation_cli.py

Guided ScienceAgentBench launcher: queues runs, records each spec as JSON notes, then starts CsvEvaluationMode one run at a time.

1 159 lines · classes: EvaluationCLI, EvalRunSpec · TOTAL_STEPS = 7 · called by main.py::main

the seven steps (EvaluationCLI.run)
1  Configuration            _load_config
   workspace resolve        _resolve_workspace
2  Agent Model Selection    _choose_agent_model      (only smolagent_model_id)
3  Toolomics / Workspace    _setup_connectivity      (port range, MCP scan)
4  Evaluation Mode          _choose_eval_mode        1 single_agent | 2 one_shot | 3 iterative
5  Task Limit               _ask_csv_runs_limit      default 200
   recovery options         _ask_recovery_options    start row, restore cache
6  Advanced / Ablation      _configure_advanced_options
7  Queue Summary & Launch   _print_queue_summary, _launch_queue

Each run is a deep copy of the base config (copy.deepcopy). Per-run dirs are set in _run_single_eval: sources/workflows/run_<id>, sources/memory/run_<id>, ./tmp/run_<id>, runs_capsule/run_<id>. Notes are written by _save_start_notes and merged by _update_notes into run_notes/evaluations/<ts>_run<id>_<model>_<mode>.json. A failing run is recorded and the queue continues; a run aborted by a network outage is marked network_failure (_network_aborted).

advanced knobs offered (_configure_advanced_options)
workflow_llm_model, orchestrator_choose_model, literrature_grounding
selection_strategy (qd | tournament | greedy | novelty)
novelty_weight (0.0-1.0), max_learning_evolve_iterations, learned_score_threshold
crossover_rate, population_size

Four knobs are tagged "learning only" and are ignored unless the run is iterative. Strategy values match sources/core/selection.py.

sources/cli/memory_chat_cli.py

Read-only curses chat over one finished run: loads memory JSON chunks, embeds them, retrieves the top 5, answers through judge_model.

652 lines · classes: MemoryChatCLI, MemoryIndex, MemoryChunk · called by main.py::main

how it reads a run's memory
MemoryChatCLI.__init__      -> resolve_run_dir(config, run_uuid): uuid, else newest mtime
MemoryChatCLI.run           -> _bootstrap(): load_memory_chunks, MemoryIndex, _build_llm
load_memory_chunks(dir)     -> one chunk per smolagent step, or one per single-call file
MemoryIndex.search(query)   -> cosine top 5, TOP_K = 5
MemoryChatCLI._ask          -> rewrite_query, then answer_with_context
MemoryChatCLI._loop         -> keys: a ask, arrows scroll/navigate, c code, r reload, q quit
MemoryChatCLI._handle_reload-> re-reads dir, rebuilds the embedding index

Embedding model: sentence-transformers/all-MiniLM-L6-v2 (DEFAULT_EMBED_MODEL), downloaded on first use. Two LLM calls per question, both on config.judge_model (_build_llm). Chunk code/trim primitives come from sources.transparency.memory_trace (extract_code, trim). The CLI writes nothing.

Red note: docs/usage/transparency.md line 13 tells users to run uv run memory_explorer.py <uuid>, but no such file exists in the repository (git ls-files finds none).

term_width()                   max(40, min(cols - 4, MAX_WIDTH))
banner(console, tagline)       figlet MIMOSA banner
step_header(step, total, title, show_progress)   progress track ▰▰▱

FORCE_COLOR turns styling back on. Colour support is decided once at import time (_ENABLED), so the env vars must be set before the import.
