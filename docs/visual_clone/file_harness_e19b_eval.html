e19b_eval.py

This script is the confirmatory readout of the E19b variants: it reads the benchmark success label once per selected config. It fits Bradley-Terry rewards per group for three aggregation arms, then reports pairs-correct over the contrast pairs with cluster-bootstrap confidence intervals, M2 replay, claim-category discrimination and cost. It writes one JSON and one markdown report.
