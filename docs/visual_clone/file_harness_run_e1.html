run_e1.py

This is the E1 rubric-surgery runner: it re-reads the frozen claim parse, re-scores the 607 examples under aggregation variants, measures every variant with metrics.py, and writes one dated JSON. It runs on demand, never on import, through uv run python -m experiments_verifiers.harness.run_e1 (L7). E1 touches no artifacts, so it ships no sabotage control (L447).
