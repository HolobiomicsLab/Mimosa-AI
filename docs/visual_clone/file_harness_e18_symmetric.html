e18_symmetric.py

Re-runs the cached E18 scorer scripts with the A/B candidate paths swapped, remaps the winner, and aggregates the two orderings. It makes zero LLM calls and appends a symmetric_reaggregation section to the existing E18 result files. Run it from the repo root with uv run python experiments_verifiers/harness/e18_symmetric.py.

Diagram 1 — what the file does

Diagram 1 — 8 boxes. Pill = function, rectangle = data file, dashed = read/write. phase_symmetric calls load_main and done_keys; it submits rerun_swapped per undone pair; rerun_swapped calls E18.execute_script, E18.parse_script_output, E18.all_metrics_null and swap_winner. main then reads the ledger back, aggregates, refits BT and writes the E18 files. The E18.GUARD snapshot check runs in main (L135, L138) and is drawn in Diagram 2.

Diagram 2 — data in and out

Diagram 2 — 9 boxes, dashed = reads or writes. main() returns nothing: the result is the two rewritten E18 files plus the appended ledger. Paths are built from EV / "results" (L35, L42–45). E15_bt_pilot and verifier_claims_sane.jsonl supply the comparison arms; the original E18 rewards come back out of OUT_JSON at L259.

Diagram 3 — selection rule and loop guard

Diagram 3 — the loop and the decision rule, with the real conditions. The queue filter and resume test are at L101–104, the execution test in rerun_swapped at L82–84, the aggregation branch at L193–207, the failure counter at L196–198, and the guard assertion at L139.
