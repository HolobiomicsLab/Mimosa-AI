e24_gradient_duel.py

This file is E24 Phase 4: it writes one measured-facts gradient per generation and then judges five gradient channels against each other with the E16v2 instrument. The gradient text holds only execution facts — re-execution status, what diverged, and the verifier-owned holdout metric against the group field — never SR, VER or reward. It runs by hand: uv run python experiments_verifiers/harness/e24_gradient_duel.py (entry point main() L237).
