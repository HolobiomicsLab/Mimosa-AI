genotype_embedding.py

Turns one generated workflow source text into one unit-norm vector, so the QD novelty axis can measure how different two genotypes are. The default backend is the local all-MiniLM-L6-v2 model, loaded from the Hugging Face cache with no network call; an OpenAI backend is optional. The selection layer consumes the vector through code_features.py.
