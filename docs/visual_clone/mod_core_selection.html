Selection: archive, qd_score, novelty

SelectionPressure decides which generated workflow survives, and WorkflowSelector draws the parents for the next generation. selection.py holds the four selection modes and the in-memory QD archive; workflow_selection.py turns archive or disk records into WorkflowInfo parents.

Selection modes

selection_strategyValidator calledDecision
greedy_validate_greedyAccept when relative improvement beats min_improvement_threshold; parent = best reward.
tournament_validate_tournamentSample 3 baselines; near-neutral accepted at 50 %, regression at exp(-10*|delta|).
novelty_validate_open_endedArchive + qd gate; same code path as the next row.
qd (default)_validate_open_endedAdmit when improving or qd_score > admit_threshold.

novelty and qd are one code path: validate_survivor routes both to _validate_open_ended (selection.py:181) and select_parent treats them together (selection.py:218). Only the strategy string in the result differs. Any unknown strategy value falls back to greedy.

Elite handling

There is no separate elite list. A high-qd_score member stays because _add_to_archive evicts the lowest-qd_score peer when the list exceeds population_size (selection.py:576-591). After every admission, _refresh_member_metrics recomputes novelty_score and qd_score for all members, so an old member's rank can drop without its own evaluation changing.
