tools_manager.py

This file finds the MCP servers on the configured addresses and turns each one into Python client code for the generated workflow. Its classes Tool and MCP hold a server and its tool list; ToolManager does the discovery. It runs at the start of every generation, through Factory.load_tools_code (factory.py:35).

Method defaults are wider than the config default: discover_mcp_at_address defaults to port_min=5000, port_max=5250 (lines 433-434), while config.py:49-51 sets 0.0.0.0 port range 5000-5200. Every caller passes the config values (line 489), so the defaults are never used on the repo paths.

ToolHive discovery is disabled at its only call site: line 536 is a commented-out call, and line 537 forces mcps_thv = []. So discover_toolhive_servers and its three restart helpers, plus all five subprocess calls, are unreachable from the normal path. The network scan at http://<ip>:<port>/mcp is what runs.
