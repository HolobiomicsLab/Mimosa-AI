Run artifacts on disk

One campaign writes four trees: per-task records in run_notes/, the shipped workspace in runs_capsule/, the per-generation genotypes in sources/workflows/, and volatile workspace copies in /tmp/mimosa_run_*. This page measures those trees and names the code that writes them. All counts are a snapshot of this working tree on 2026-09-28; a campaign was still writing into the run_1 folders.

Code that writes and reads the artifacts

sources/benchmark_evaluation/csv_mode.py

Runs the CSV campaign, calls the ablations, writes the per-task run note; stamps leak keys in gold mode.

CsvEvaluationMode · 1901 lines · writers: _save_run_notes, _evaluate_snapshot_ablations, _stamp_gold_capsule_results · reader: _load_previous_run_notes

sources/benchmark_evaluation/capsule_evaluator.py

Grades one capsule or one /tmp snapshot, then stores the verdict.

CapsuleEvaluator · evaluate_all, save_results writes evaluation_results.json

sources/core/evolution_engine.py

Writes the per-generation metrics, prompt, plots and QD trails.

EvolutionEngine · _persist_iteration_metrics, _save_evolution_prompt_artifact, _save_final_plots

sources/utils/run_metrics.py

Filesystem helper: dumps one metrics dict to run_metrics.json, appends JSONL lines.

71 lines · write_run_metrics, append_jsonl · schema owned by evolution_engine

sources/utils/transfer_toolomics.py

Names the capsule and copies the workspace into runs_capsule/.

LocalTransfer · create_capsule_folder, transfer_workspace_files_to_capsule

sources/utils/workspace_management.py

Copies the workspace to /tmp/mimosa_run_<session>_<uuid> after each round.

WorkspaceManager · save_run_snapshot, restore_best reads the copies back

sources/benchmark_evaluation/snapshot_grading.py

Grades one directory with CapsuleEvaluator; returns VER/SR/CBS; never calls save_results.

82 lines · grade_directory · callers: ablation loop, gold grader

sources/evaluators/gold_feedback/evaluator.py ORACLE

Gold-mode verifier; writes gold_feedback.json, both gradients and the evaluation.txt leak banner.

GoldFeedbackEvaluator._persist · page: mod_evaluators_gold_feedback.html, file_gold_evaluator.html
