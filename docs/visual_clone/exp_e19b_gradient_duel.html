e19b_gradient_duel — five-way gradient comparison

This phase compared the V5 gradient text (decisive losses first, transcript demoted) against four earlier channels on the same 123 paired generations. The script swaps in the e19b gradient text and judges all five sides with the identical E16 v2 prompt, so only the e19b side needed new calls. The text comes from e19b_dryrun; the shipped package is hybrid_verifier.
