reward.py

This 26-line file holds one function, oracle_reward, the full-oracle reward: 1.0 when SR passes, 0.5 x CBS after a clean re-run, else 0.0. GoldFeedbackEvaluator calls it only when gold_feedback_reward is True and the grade is not censored.
