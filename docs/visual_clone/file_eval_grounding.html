grounding.py

This 55-line file holds one function, get_perspicacite_grounding(goal), which builds a long literature-grounding prompt and sends it to the local Perspicacite retriever. It runs when an evaluator asks for the literature's expectations about a task goal. It reads no config key and writes no file itself.

The legacy verifier keeps a failure marker of its own (legacy_verifier/verifier.py::_GROUNDING_FAILED_MARKER L239, used at L261), but it needs the callee to raise, and this file swallows the exception first.
