e13_common — shared E13 machinery

E13 ran twelve candidate scorers; each one had to be measured with the same protocol. This module holds that protocol: two frozen universes, the LOTO fold loop with its inner-CV C grid, the paired statistics, and the JSON reader/writer. E13's answer (no deeper manifold beats linear L3 for picking) is only readable because every arm went through these same functions.
