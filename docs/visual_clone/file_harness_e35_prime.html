e35_prime.py

This file is the E35 "PRIME" harness: it builds one verifier prototype from six already-measured wins and grades it on the frozen E14 arena, then judges the gradients it produced. It runs by hand, one subcommand at a time, and calls the production hybrid_verifier modules in process without editing any of them. The text judge is openrouter/deepseek/deepseek-v4.1-flash L149, the vision judge is openrouter/moonshotai/kimi-k3 L150, and the HARD cap for all of E35 is $20.00 L156.
