sources/utils - shared helpers

Twenty helper modules live in sources/utils/. Three caller areas import them: sources/core, sources/cli and sources/benchmark_evaluation. This page groups the helpers, lists every file, and opens cards for the five files that carry the real logic.

The XDG against checkout rule

sources/utils/paths.py::is_repo_checkout checks for pyproject.toml next to the package. paths.py::state_dir then picks where mutable state goes: inside the checkout for repo runs, under the XDG dirs for installed runs.

installed runs: ~/.config/mimosa (config.json, .env), ~/.local/share/mimosa (memory, workflows, runs_capsule), ~/.cache/mimosa (tmp, openrouter_pricing.json) repo checkout: sources/memory, sources/workflows, runs_capsule/, tmp/, sources/cache/openrouter_pricing.json

Path: sources/utils/paths.py - functions is_repo_checkout, state_dir, default_memory_dir, default_workflow_dir, default_runs_capsule_dir, default_tmp_dir, pricing_cache_file. paths.py::resource_path always stays package-relative, so prompts and module templates load from either layout.

sources/utils/workspace_management.py

Snapshots the workspace once per session, resets it before each run, stores each run under /tmp, and restores the best run at the end.

169 lines · class: WorkspaceManager · uses LocalTransfer from transfer_toolomics.py

signatures and session order
WorkspaceManager(config, logger=None)
  .session_id -> str | None          # property, 12 hex chars
  .begin_session() -> None           # backup + clean + restore
  .reset_for_run() -> None
  .save_run_snapshot(run_uuid) -> Path    # /tmp/mimosa_run_<session>_<uuid>
  .restore_best(best_uuid) -> None
  .cleanup() -> None
  ._backup_initial_workspace() -> Path    # /tmp/mimosa_initial_<session>

Call order from the class docstring: begin_session → (reset_for_run, run, save_run_snapshot) per generation → restore_best → cleanup. _assert_session raises RuntimeError when begin_session was skipped. cleanup() returns without globbing when no session id exists, so it cannot delete another worker's /tmp folders.

Called by main.py and sources/core/evolution_engine.py.

sources/utils/perspicacite_client.py

Sends the task to the Perspicacite-AI RAG service over SSE streaming, falls back to plain JSON, and caches each answer on disk.

394 lines · cache key = sha256 of query and mode · returns None when the service is down

Timeouts: connect 30 s, read 600 s, write 60 s, pool 30 s. Base URL comes from PERSPICACITE_API_URL, default http://localhost:5468. Sends max_papers = 5 and databases semantic_scholar, openalex, pubmed. Cache files: sources/memory/perspicacite_requests/<key>.json. A failure logs a warning and workflow generation continues without grounding.

Called by sources/core/orchestrator.py, sources/core/planner.py and sources/evaluators/grounding.py.
