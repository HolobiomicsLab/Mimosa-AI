claims.py

This file writes the two claim prompts (extract once per task, refine replacements later) and validates what the judge returns as ladder claims. It runs inside ClaimsEvidenceLayer.collect and ClaimsEvidenceLayer.revise (layers.py), once per task and once per generation. The same ladder is described on the hybrid_verifier page and in flow_verification.html.
