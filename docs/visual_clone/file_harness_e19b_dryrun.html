e19b_dryrun.py

This script picks the E19b variant without touching a single benchmark label. It loads five configs (two claim sets, three score ledgers), scores the planned generation pairs under three aggregation rules, writes V5 gradient texts and judges a declared 5-group pilot. It runs from the command line with three subcommands: proxies, gradients and pilot-judge.
