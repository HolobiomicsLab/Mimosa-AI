e15_bt_pilot — the live judging engine

E15 asked whether a paid LLM preference tournament over frozen generation artifacts is affordable and usable. This script executes the 667-pair plan written by E14: it judges every pair in both listed orders, breaks disagreement with a third vote, and appends one record per pair and one line per call. It spent $44.89 against a $40 cap because a duplicate judge process ran concurrently.

The cap breach is an operational accident, not a protocol cost: the JSON states at line 411 that a first judge process was believed dead, a second was started, and both double-judged 321 pairs. The judgments file keeps the first record per pair, so its 1 439 kept calls are below the ledger's 2 146 lines. The JSON also mentions "4 pre-fix smoke calls" while the ledger holds 2 parse_fail lines; the two counts measure different things, and the record does not reconcile them.
