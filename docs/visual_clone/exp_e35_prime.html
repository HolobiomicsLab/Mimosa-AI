e35_prime — verifier v3, every measured win in one prototype

E35 asks what happens when six already-measured verifier wins are put in one prototype and scored on the frozen E14 arena (19 groups / 148 generations / 667 pairs). The prototype joins the E30 content lever, the E29 T1 firewall, the E26 visual rung placed first, the E24 execution gate and the E19c win-rate reward, then grades the result with the E16v2 gradient judge. Ranking is mixed: e35_online pairs-correct 0.7075 sits below e30_online 0.7585 and e19c_online 0.7415 with every paired CI spanning 0, while gradient relevance 0.690 is the best measured on this population.
