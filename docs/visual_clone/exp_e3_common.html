e3_common — the shared E3 harness

E3 asked whether two LLM families from different labs, each writing and answering its own binary checklist, rank benchmark artifacts better than the recorded verifier reward. e3_common.py is the layer both E3 runners import: it loads the frozen population, builds bounded artifact previews, and caches every judge call on disk. It holds no experiment logic of its own, and the reward it competes with is written by the hybrid verifier.
