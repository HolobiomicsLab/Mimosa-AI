schema.py

sources/core/schema.py defines the record types the planner and the evolution loop pass around: PlanStep, Plan, Task, IndividualRun, SelectionLog, plus the TaskStatus and TaskComplexity enums. It holds no logic beyond validation: the two __post_init__ methods and two __str__ methods are the whole behaviour. It runs whenever one of those objects is constructed, which happens once per plan step and once per evolution generation.
