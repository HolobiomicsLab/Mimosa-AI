e19c_confirm.py

One-shot confirmatory readout for the E19c "ratchet" experiment: it joins the frozen label-free ledger with the E19/E19b/E24 baseline tables and scores every arm on the 147 contrast generation pairs. It is the only stage of the E19c chain that reads SR labels, and it reads them once; it makes zero LLM calls (docstring L1-17). It writes results/E19c_ratchet_2026-09-25.json and .md (L40-41).
