evaluator.py

This 470-line file holds GoldFeedbackEvaluator, the verifier the facade builds when config.verifier_kind = "gold". It runs an inner HybridVerifierEvaluator, grades a private copy of the workspace with the benchmark grader, and replaces the steering text with the grader feedback; with gold_feedback_reward = True it also replaces the reward. Package view: mod_evaluators_gold_feedback.html.
