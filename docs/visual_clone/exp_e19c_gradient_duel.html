E19c RATCHET — seven-channel gradient duel

Does the ladder's elimination-point-first gradient give better feedback than the six earlier feedback channels? e19c_gradient_duel.py judges every E19c gradient with the E16v2 instrument, side by side with the cached gradients of E19b, E19, E18, E15, E24 and the recorded verifier. It writes one JSON and one markdown with the paired deltas.
