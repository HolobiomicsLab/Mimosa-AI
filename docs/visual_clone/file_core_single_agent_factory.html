single_agent_factory.py

This file builds the source text of a one-agent SmolAgent script, instead of a LangGraph workflow. It runs in single-agent mode (main.py --single_agent), reached from WorkflowOrchestrator._generate_workflow_code. The file itself writes only metadata; the emitted script does the agent run.
