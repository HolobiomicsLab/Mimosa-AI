Evolution engine (core L2)

The evolution engine runs the per-task generation loop: it proposes a workflow, runs it in the sandbox, scores it with the verifier, and stores the result. This page maps the class, one generation, and the config knobs it reads. The generation budget is max_learning_evolve_iterations = 16 in --learn mode, and 1 otherwise.

Amber note: config.py sets crossover_rate = 0.4 while config_default.json ships 0.25; runs that load the template get 0.25.

Red note: docs/concepts/evolution-engine.md states parent_threshold_similarity default 0.8, but config.py:152 and config_default.json both set 0.95; the 0.8 in the engine is only a getattr fallback.

error paths (on_error)
  • executed = False comes from orchestrate_workflow. Generation failure returns the placeholder uuid generation_failed (see orchestrator.py::WorkflowOrchestrator._parse_generation_error); execution failure returns the real uuid.
  • The judge is skipped when executed is False (evolution_engine.py:779), but the cost is still computed.
  • The depth stop test is skipped for on_error rounds, so a failed round keeps the loop running.
  • record_lineage writes nothing when the uuid folder is missing, so generation_failed rounds leave no lineage file.
  • The observer call variation.record_offspring_gradient treats on_error or verifier skipped_reason == "workflow_generation_or_execution_failed" as a failure.

QD-facing shim: returns the unit-norm genotype embedding, or None when the source is missing, empty, or the backend fails.

37 lines · 1 function: genotype_embedding_descriptor · calls: genotype_embedding.embed_genotype · caller: selection.py:488

signature and behaviour
genotype_embedding_descriptor(code: str | None) -> list[float] | None

Returns a plain list[float] so the selection layer can fall back to a neutral novelty signal. A degenerate input gives None, never a maximum-novelty value. The __main__ block asserts unit norm within 1e-4.
