orchestrator.py

sources/core/orchestrator.py holds WorkflowOrchestrator: it turns a goal plus craft instructions into one generated workflow genotype, then runs that genotype inside the Python sandbox. It runs once per evolution candidate, because EvolutionEngine calls orchestrate_workflow() for every generation (sources/core/evolution_engine.py:495). The call returns the four-tuple (output, uuid, workflow_genotype_code, executed), and the evolution loop turns executed=False into on_error = True (sources/core/evolution_engine.py:510) before it retries.
