e12_falsifier — instability-discounted weights falsifier

E12 asked whether flaky claim verdicts mislead the within-task picker, and whether discounting the flaky claims fixes it. The gate was pre-registered: net ≥ +2 shipped tasks over v0 and within-task pairs-correct ≥ 0.754. The answer was no, so the E11 line (within-task weight fitting) closed.
