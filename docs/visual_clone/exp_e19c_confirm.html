E19c RATCHET — confirmatory readout

Does the production temporal ladder beat flat aggregation at ranking, and how do the E19c arms compare with the earlier cycle-2 channels? e19c_confirm.py opens the label-free table once, joins the frozen E19/E19b/E24 per-generation tables, and computes pairs-correct, paired deltas, M2 replay and independence. This is the only E19c stage that reads the SR labels.
