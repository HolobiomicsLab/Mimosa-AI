E19c RATCHET — online Bradley-Terry default

The hybrid verifier promoted aggregation.bradley_terry_reward to its default reward, so does that default rank better than the earlier win-rate view on the same arena? e19c_online_bt.py replays the production BT fit over {generation k} plus every earlier generation, in evolution order, on the stored vectors. It appends one section to the E19c results with zero LLM calls.
