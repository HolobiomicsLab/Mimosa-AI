inventory.py

This file lists every file of a workspace with its size and, when cheap, a CSV shape or PNG size. Claim extraction and scorer prompts read those listings, so the judge sees which paths exist and which are stable across generations. It runs on every evaluated generation, called from evaluator.py and from layers.py; the package context is on mod_evaluators_hybrid_verifier.html.

Why it matters: prompts that write claims and scorer scripts see real file names and real CSV widths, so a scorer matches the layout that exists.

Budget note: the file caps its own work with constants at the top — 300 union lines, 14 KiB of previews, 3 preview files, 11 CSV head lines, 6 KiB text head (21-28); all are module constants, not config keys.
