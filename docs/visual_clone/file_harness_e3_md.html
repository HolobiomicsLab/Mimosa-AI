e3_md.py

This is the renderer for the E3 markdown summary: it reads one dated results JSON and appends seven sections, including a success-gate verdict. It runs by hand, once, after a report stage; the input name is pinned by DATE L12. All numbers it prints are recomputed from the JSON, not measured here.
