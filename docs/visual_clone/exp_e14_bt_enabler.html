e14_bt_enabler — BT arena and tournament choice

E14 asked which frozen campaign groups can be re-judged by pairwise preference, and which pairing design is worth its call budget. It joined the run-notes manifest to the live snapshot folders, then simulated seven pairing designs over 360 cells. The pair plan it wrote is the input the E15 pilot executed and the E15 evaluation scored.
