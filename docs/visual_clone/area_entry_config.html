Entry point and configuration

The shell calls main.py::cli_main, which parses 41 flags and dispatches to one of eight modes. config.py::Config holds every default, then reads a JSON file and applies CLI overrides. This page covers the six files of the entry and config area, plus the verifier_kind choice (hybrid, legacy, gold).

18 flags are declared in main.py::main itself. 41 in total. Three flags use argparse.BooleanOptionalAction and also accept a --no- form: --gold_feedback_reward, --hybrid_verifier_visual_rung, --hybrid_verifier_execution_gate (default None = keep the config value).

Before the dispatch chain main.py::main also calls apply_config_overrides, warn_gold_feedback_mode, validate_environment, Config.create_paths, Config.validate_paths and builds WorkspaceManager. Every argument-driven mode, --manual included, therefore needs one API key from validate_environment.

config defaults versus the local JSON template (my computation)

7 of the 58 JSON keys hold a different value from the config.py default: workflow_llm_model (glm-5.3-prime vs glm-5.3), judge_model (xiaomi/mimo-v2.6-pro-ultraspeed vs deepseek-v4.1-flash, not read, see red note), learned_score_threshold (0.92 vs 0.9), crossover_rate (0.25 vs 0.4), hybrid_verifier_num_claims (16 vs 10), hybrid_verifier_scorer_timeout_s (120 vs 60), hybrid_verifier_digest_max_files (16 vs 8). Path, secret and provider-list keys were not compared.

3 keys Config.jsonify writes are absent from the local file: capsule_namer_model, hybrid_verifier_visual_rung, hybrid_verifier_execution_gate. The file has the gold keys verifier_kind (hybrid), gold_feedback_reward (false) and gold_feedback_timeout_s (1800).

2 fields set in Config.__init__ are absent from jsonify and from_json, so a JSON file cannot set them: literrature_grounding (this spelling) and orchestrator_choose_model. tests/config_roundtrip_test.py records both in KNOWN_GAPS (issue #182). 2 more are runtime-only by design: gold_feedback_task_row, gold_feedback_sab_loader (NOT_PERSISTED).

Config.jsonify emits 61 top-level keys; the local config_default.json has 58. Computed with uv run python on Config().jsonify(), 2026-09-28.

Order inside main.py::main: dotenv.load_dotenv at import, then argparse, config load (--config, else the installed user config), logging, ensure_environment(auto_install=True), the three early-return branches, apply_config_overrides, warn_gold_feedback_mode, validate_environment, path checks, WorkspaceManager, then the dispatch chain.

main.py::warn_gold_feedback_mode returns False unless verifier_kind is gold. Then it prints LEAK_WARNING (from sources/evaluators/gold_feedback/leak.py), a FULL ORACLE line when gold_feedback_reward is true, and a hybrid-fallback line without --science_agent_bench. Returns True.

main.py::main raises ValueError("No goal provided. Use --task, --goal to start.") when normal_execution_mode gets no task, goal or scenario.
