Entry point and configuration

The shell calls main.py::cli_main, which parses 48 flags and dispatches to one of eight modes. config.py::Config holds every default, then reads a JSON file and applies CLI overrides. This page covers the six files of the entry and config area, plus the verifier_kind choice (policy_bt run default, hybrid previous, legacy, gold).

18 flags are declared in main.py::main itself. 48 in total. Seven flags use argparse.BooleanOptionalAction and also accept a --no- form: --gold_feedback_reward, --hybrid_verifier_visual_rung, --hybrid_verifier_execution_gate, --policy_bt_visual_channel, --policy_bt_refiner, --policy_bt_visual_tiebreak_code, --policy_bt_verbose (default None = keep the config value).

5 names are read by main.py::apply_config_overrides with getattr, but no parser declares them, so no CLI flag can set them: early_stop_mode, min_learning_evolve_iterations, plateau_patience, explore_after_plateau and explore_base_rate (a grep for "--early_stop_mode", "--min_learning_evolve_iterations", "--plateau_patience", "--explore_after_plateau" and "--explore_base_rate" finds no add_argument; 2026-10-10). Set them through the JSON config.

Before the dispatch chain main.py::main also calls apply_config_overrides, warn_gold_feedback_mode, validate_environment, Config.create_paths, Config.validate_paths and builds WorkspaceManager. Every argument-driven mode, --manual included, therefore needs one API key from validate_environment.
