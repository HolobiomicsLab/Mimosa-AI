Entry point and configuration

The shell calls main.py::cli_main, which parses 37 flags and dispatches to one of eight modes. config.py::Config holds every default, then reads a JSON file and applies CLI overrides. This page covers the six files of the entry and config area.

Amber note: --evaluation_cli, --memory_cli and the no-flag wizard return before apply_config_overrides, so flags such as --runner_default_timeout do nothing there.

Red note: docs/reference/cli.md lists 35 of the 37 flags; --hybrid_verifier_reward and --planner_human_approve are missing (checked with grep at this commit).

the other flags: behaviour, logging, batch

--csv_runs_limit (int, default 200), --disable_judge, --debug, --verbose, --memory_uuid, --max_evolve_iterations (writes config.max_learning_evolve_iterations).

19 further flags come from main.py::add_config_arguments and are applied by main.py::apply_config_overrides: --workflow_dir, --schema_code_path, --smolagent_factory_code_path, --prompt_workflow_creator, --runner_default_python_version, --runner_default_timeout, --runner_default_max_memory_mb, --runner_default_max_cpu_percent, --runner_temp_dir, --pushover_token, --pushover_user, --verifier_kind, --hybrid_verifier_num_claims, --hybrid_verifier_refinement_rounds, --hybrid_verifier_scorer_timeout_s, --hybrid_verifier_digest_max_files, --hybrid_verifier_pairwise_mode, --hybrid_verifier_reward, --planner_human_approve.

Before the dispatch chain main.py::main also calls apply_config_overrides, validate_environment, Config.create_paths, Config.validate_paths and builds WorkspaceManager. Every argument-driven mode, --manual included, therefore needs one API key from validate_environment.

config defaults versus the JSON template (my computation)

4 of the 56 JSON keys hold a different value from the config.py default: smolagent_model_id (deepseek-v4-flash-0731 vs deepseek-v3.2), learned_score_threshold (0.9 vs 0.92), max_concurrent_eval_tasks (1 vs 2), crossover_rate (0.4 vs 0.25).

1 key Config.jsonify writes is absent from the template file: capsule_namer_model.

2 fields set in Config.__init__ are absent from jsonify and from_json, so a JSON file cannot set them: literrature_grounding (this spelling) and orchestrator_choose_model. tests/config_roundtrip_test.py records both in KNOWN_GAPS (issue #182).

Config.jsonify emits 57 top-level keys; config_default.json has 56.

Config.load raises FileNotFoundError when the file is missing. Config.validate_paths asserts that workflow_dir, schema_code_path, smolagent_factory_code_path, prompt_workflow_creator, prompt_planner and workspace_dir exist; create_paths creates workflow_dir, memory_dir and runner_temp_dir.

AddressMCP.__post_init__ rejects empty IPs and a port outside 0-65535, and fails if port_min > port_max.

Mutable state lives under paths.py defaults: sources/workflows, sources/memory, runs_capsule/, tmp/ in a checkout, XDG dirs in an installed run.
