run_e2.py

This is the E2 static-grounding harness: it scores every frozen workspace of the manifest under two check sets (strict6 and extended), measures them with metrics.py, runs a sabotage control on copies, and writes one dated JSON. It runs on demand through uv run python experiments_verifiers/harness/run_e2.py (L9). The DATE constant is pinned to 20260921 (L33), so a rerun overwrites the same file.
