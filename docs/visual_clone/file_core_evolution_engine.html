evolution_engine.py

This file holds class EvolutionEngine (line 65) plus two module helpers, and it runs the per-task generation loop: build a workflow, run it, score it, keep the best. start_workflow_evolution (line 338) opens one task and evolve_generation (line 454) recurses once per generation. The loop stops on max depth, on the score threshold, or when learning mode is off; mod_core_evolution_engine.html maps the class, this page maps the file.
