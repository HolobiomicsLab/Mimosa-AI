evolution_engine.py

This file holds class EvolutionEngine (line 175) plus five module functions, and it runs the per-task generation loop: build a workflow, run it, score it, ship the best. start_workflow_evolution (line 448) opens one task and evolve_generation (line 560) recurses once per generation. The loop stops on max depth, on the score threshold, or when learning mode is off; mod_core_evolution_engine.html maps the class, this page maps the file.
