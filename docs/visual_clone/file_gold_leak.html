leak.py

This 29-line file holds the leakage warning LEAK_WARNING and leak_banner, which frames it between two lines of 78 !. Every gold-mode artifact carries this text, so a run that used the benchmark gold is never read as an honest Mimosa score. It has no logic and no I/O.
