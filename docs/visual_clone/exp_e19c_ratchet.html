E19c RATCHET — builds the production ladder pipeline

Does the production temporal-ladder verifier rank like the benchmark on the frozen arena? e19c_ratchet.py is the pipeline that measures it: it replays the production hybrid-verifier stages over the frozen arena, prompting only the task goal and workspace inventories. It writes four resumable ledgers, one cost ledger and one registry per scored group; exp_e19c_eval.html and exp_e19c_confirm.html read those files.
