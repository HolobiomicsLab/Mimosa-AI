e3_common.py

This file is the E3 shared harness: it loads the frozen population, builds bounded workspace evidence packets, and wraps litellm in a disk-cached async client. It has no command line; the three E3 runners and the judge module import it as C. The evidence budget (10 files, 2 KB heads, 24 000 characters) is what keeps every judge prompt small L113–L114.
