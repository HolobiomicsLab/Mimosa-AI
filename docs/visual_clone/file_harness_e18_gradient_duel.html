e18_gradient_duel.py

This script runs the three-way feedback duel: one identical E16 judge prompt is applied to each generation with the E18 scripted gradient, the E15 preference gradient and the verifier gradient, then the three readings are compared pairwise. It runs as uv run python experiments_verifiers/harness/e18_gradient_duel.py and writes results/E18_gradient_duel_2026-09-23.json plus a markdown copy. The E18 side makes new calls; the E15 side and the verifier side are cache hits (docstring L28–L34).
