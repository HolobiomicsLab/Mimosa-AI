Experiment trees

The verifier program now spans E1–E48 (cycles 1–5): cycle 1 (E1–E11) proved the legacy reward anti-correlates with benchmark success, and cycles 2–5 built 10+ verification architectures, shipped a production replacement and audited the frozen arena's own labels. Cycle 5 closed with E44 KUMITE (2026-10-02), an honest-negative replay of a BT-over-policy-script verifier, then E45 SPARTAN (2026-10-02) verified it adversarially: the v2 relevance gain was a naming artifact; the v2b instrument and a quarantined holdout re-measured the content levers. E46 (2026-10-03) then added kimi-k3 figure scoring for the 6 visual-judge tasks onto the v3 policy behind the exec-crash rung; E47 REFINER (2026-10-03) refined those gradients with an evidence-checking LLM pass (verified issues, missing-file flags, corrections) — relevance-neutral under v2b, grounding real; E48 FIXES (2026-10-03) applied the audited 5-fix list and re-ran: coverage 17/19→19/19, non-visual pooled 0.7482, visual pairs 6/6. The shipped verifier is sources/evaluators/hybrid_verifier/ and the ranked next steps are HANDOFF.md §5. Here is the folder map and the per-experiment evidence.

E45 SPARTAN — adversarial verification of E44; instrument v2b + quarantined holdout

E45 (2026-10-02) attacks E44 before trusting it: a placebo probe (gradients holding only the coverage footer) scored 0.62 vs real 0.51 under the E16v2 relevance judge, so the v2 gain 0.188→0.504 was mostly a naming artifact and the design was in-sample. Fix set: a v2b assessment-scoring instrument (naming counts zero), a quarantined 7-task holdout whose gates were read once, a substance-only v3 arm and a no-recon generic control.
