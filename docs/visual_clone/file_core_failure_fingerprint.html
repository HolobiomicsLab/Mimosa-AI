failure_fingerprint.py

Turns the verifier's per-claim verdicts into a fixed-length pass-rate profile: one slot per claim source, centred on the mean of the sources that spoke. It runs inside the evaluator right after a verification round, and the profile is persisted into state_result.json. The module header marks the descriptor as deprecated (line 3), so the QD archive no longer reads it; see the selection page for the descriptor that replaced it.
