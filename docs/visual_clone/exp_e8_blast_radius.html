e8_blast_radius — how far did the note bug spread?

An infra-excluded capsule dropped out of _save_run_notes, so the run note of that task was written from the previous evaluated task's execution data. This experiment finds every affected task by three independent signals, recovers the real per-generation verdicts from the evaluation log, and rebuilds the sane datasets. Folder context: data_experiments.html.
