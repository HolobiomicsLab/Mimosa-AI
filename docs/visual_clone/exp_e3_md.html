e3_md — the E3 markdown summary writer

E3 asked whether two LLM families, each writing its own binary checklist, rank benchmark artifacts better than the recorded verifier reward. e3_md.py turns one E3 results JSON into the human-readable markdown summary with a three-part success gate. It reads results/E3_designA_20260921.json and writes results/E3_designA_20260921.md; neither file exists on disk.
