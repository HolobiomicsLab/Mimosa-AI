claims_pattern_analysis.py

This script measures the hidden structure of one campaign's verifier claims: it embeds every unique claim name with MiniLM, picks the cluster count k by silhouette, profiles each claim cluster, groups tasks by Jaccard overlap of their claim sets, and links claim families to benchmark SR. It runs offline from the command line, needs plotly, and writes one single-file HTML report plus a cached embedding file. Nothing in the repository imports it.
