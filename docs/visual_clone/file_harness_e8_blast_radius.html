e8_blast_radius.py

This script audits the excluded-task fallback bug at sources/benchmark_evaluation/csv_mode.py:455–457: when a capsule evaluation was EXCLUDED, the run note fell back to sab_runs[-1] and carried the previous task's uuids, rewards and ablations. It finds every affected task by three independent signals, recovers the real per-generation verdicts from the log and from run_metrics.json, and writes corrected datasets plus a before/after E4 policy table. Everything it reads is read-only evidence; run it with uv run python experiments_verifiers/harness/e8_blast_radius.py.

Diagram 3 — the selection rule replayed per task

Diagram 3 — 8 boxes. shippable_of (L312) keeps only generations that are not failed_slot and whose status is evaluated. The four policies then differ only in which rank they ship: P0 the top of ranked_desc (L325), P1 the top VER-true generation, or SR False when none exists (L328–332), P2-3 the first SR-true inside the top three (L335–342), PORACLE any SR-true with its rank as the query count (L343–346). replay (L350) repeats the chosen policy over every task and every campaign. The note-to-log join uses a separate tolerance, TS_MATCH_TOL_S = 5.0 seconds (L72, used at L155).
