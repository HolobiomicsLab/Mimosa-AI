scenario/scenario.py

This 653-line file holds the class ScenarioEvaluator, which scores one workflow uuid against one scenario rubric file. It reads the rubric, sends the workflow execution text to an LLM judge item by item, and writes a score to state_result.json plus a human-readable evaluation.txt. It runs when WorkflowEvaluator.evaluate is asked for the scenario evaluation type; the module docstring states it is not used for ScienceAgentBench evaluation (L2–L3).
