Batch benchmark flow

Batch mode reads a CSV of tasks and grades each task with the ScienceAgentBench graders. --papers <csv> builds the goal from the row, and --science_agent_bench adds dataset transfer plus VER / SR / CBS grading. Every task leaves one run-notes JSON with the verifier rewards and the per-iteration ablations; in gold mode (--verifier_kind gold) the loop also hands the task row to the config and stamps leak keys.
