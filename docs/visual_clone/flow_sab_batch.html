Batch benchmark flow

Batch mode reads a CSV of tasks and grades each task with the ScienceAgentBench graders. --papers <csv> builds the goal from the row, and --science_agent_bench adds dataset transfer plus VER / SR / CBS grading. Every task leaves one run-notes JSON that holds the verifier rewards and the per-iteration ablations.

The ablation writer never calls save_results(), so the /tmp/mimosa_run_* snapshots stay unmodified (sources/benchmark_evaluation/csv_mode.py, line 894).
