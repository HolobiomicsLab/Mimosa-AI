Planner - goal mode (L0)

In --goal mode the planner turns one goal string into a JSON step list, then runs each step through the evolution engine. It reads its system prompt from config.prompt_planner, asks Perspicacité for literature context first, and can stop for human plan approval. Default: 3 plan attempts (max_retries) and 5 attempts per step (max_task_retry).
