e17_gradient_duel — which feedback channel points at gold?

E17 pitted two feedback channels against each other on the same generations: the E15 preference gradient (judges saw goal and artifacts only) and the verifier's rubric gradient. It re-judged both texts with the same E16 instrument, so only the gradient text varies. The question is whether preference-grounded feedback points at gold more often; the winning channel here is the one hybrid_verifier writes today.

Design — hypothesis, inputs, stages, artifacts

11 boxes. Mint = E17 functions, steel = data files. The decisive design fact sits on the judge_bt() box: judge_bt() rebuilds the E16 prompt and replaces E16.gradient_text(item) with the preference text (L69), so goal, gold and artifact state stay identical for both channels. The verifier side re-enters E16.judge_item() and comes back as a cache hit.

The script

experiments_verifiers/harness/e17_gradient_duel.py

Joins each preference gradient to its verifier gradient, re-judges both with the E16 instrument, and reports the paired difference with a cluster bootstrap.
