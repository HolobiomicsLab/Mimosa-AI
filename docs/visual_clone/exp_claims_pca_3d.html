claims_pca_3d — the claim space in three dimensions

This experiment asked whether claim names that several tasks share collapse onto the same point in embedding space, so generic claims can be read as colour-blended hotspots on a task-coloured cloud. The script embeds the 1 755 unique names, projects them to 3 components with PCA (seed 0), and writes one offline plotly HTML plus a CSV of coordinates. Answer: shared names do collide exactly, but the first three components carry only 12.1% of the variance, so the layout is a colour map of task frequency rather than a strong low-dimensional structure.
