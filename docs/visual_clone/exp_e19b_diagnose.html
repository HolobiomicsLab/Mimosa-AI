e19b_diagnose — why E19 v1 feedback stopped improving

Phase 1 of E19b asked why the E19 v1 hybrid verifier hit a ceiling: claims, scorers, or gradient text? The script reads the E19 v1 judge corpus, claim and score ledgers and 123 gradient files, with zero LLM calls. It returns counted themes, primary failure modes, rank correlations and six pre-registered variant hypotheses; the cluster is the direct ancestor of hybrid_verifier.

Design — hypothesis, inputs, stages, output

Design 1 — the script reads five frozen E19 v1 inputs, runs four analysis blocks, and writes one JSON plus the hypothesis map.
