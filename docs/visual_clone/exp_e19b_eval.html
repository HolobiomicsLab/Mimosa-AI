e19b_eval — confirmatory readout of hybrid_bt_v2

Phase 3 asked whether the label-free winner (v2r2) beats the E19 v1 hybrid verifier on the benchmark's own success labels. The script fits Bradley-Terry rewards per group for three aggregation arms, reads SR once per selected config, and reports pairs-correct over the 147 contrast pairs with cluster-bootstrap CIs, M2 replay and cost. Labels were touched only here, after selection; the label-free table comes from e19b_dryrun and the shipped package is hybrid_verifier.
