format.py

This 268-line file turns one benchmark grade into the gold textual gradient: the execution outcome first, then the grader verdict against the gold reference, at most 2000 chars. It also writes the short note used when grading is censored. It is pure text work; GoldFeedbackEvaluator stores the result.
