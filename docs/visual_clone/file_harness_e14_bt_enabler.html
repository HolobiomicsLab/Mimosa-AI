e14_bt_enabler.py

The zero-API enabler for the Bradley-Terry preference verifier: it maps which generation groups are still comparable on disk, simulates tournament designs and their pair budgets, projects judge cost, and writes the machine-readable pair plan that e15_bt_pilot.py executes. It runs from the repo root with one command and no arguments. Its only network touch is one OpenRouter pricing fetch, with a hardcoded fallback.
