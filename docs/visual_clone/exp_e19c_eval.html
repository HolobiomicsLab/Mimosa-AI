E19c RATCHET — label-free ranking and gradients

Which pairwise mode does the production aggregator pick, and how often do the frozen generations tie, with zero labels read? e19c_eval.py consumes the E19c ledgers, calls the production aggregation functions verbatim, and writes the label-free table. It also writes one gradient file per generation, which exp_e19c_gradient_duel.html then judges.

12 boxes. Cyan = a function of experiments_verifiers/harness/e19c_eval.py, mint = production function called verbatim, teal = the shared BT helper harness/e15_bt_eval.py, steel = data.
