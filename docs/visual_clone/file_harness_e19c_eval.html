e19c_eval.py

Offline scorer for the E19c phase-C campaign: it rebuilds every pairwise verdict from the stored per-claim scores and writes one gradient text per generation. It imports the production verifier modules verbatim (aggregation, claims, gradient) and makes no LLM call and reads no label (docstring L18). It runs as a script: if __name__ == "__main__": main() at L337–338, with a fixed output name dated 2026-09-25 (L43).
