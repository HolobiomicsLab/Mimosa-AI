e24_common.py

This file holds the shared plumbing of experiment E24: fixed paths, seeds and budgets, the five pre-registered split specs, one retrying LLM call, resumable JSONL ledger helpers, the arena loader and three small metric functions. Every other E24 harness file imports it as C and reads its constants. It has no command-line entry point: it runs only when imported.

Diagram 1 — the module is a library, not a program: constants L37–L126, then four helper groups. call_llm L160 is the only function that reaches the network; load_arena L247 is the only one that reads the frozen arena.

Diagram 3 — logic: the retry loop of call_llm and the snapshot guard

Diagram 3 — the loop is for attempt in range(6) L169. Fallbacks: double max_tokens when the content is empty or finish_reason == "length" L197, and a wait of min(45, 2**attempt*3) seconds after any other error L209. The call timeout is 120 s L176.
