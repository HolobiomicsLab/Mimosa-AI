e19_hybrid_bt — claims, scorers, ledgers

This experiment asks whether a few curated, task-defining claims plus one deterministic scorer per claim can rank the 667 generation pairs of the E14 arena. The script extracts 3-7 claims per group, writes one scorer per claim, and runs that same script on every workspace of the group. It writes four ledgers and a pilot gate record; the ranking readouts live in exp_e19_bt_eval.html.

Design — one judge call per group, one scorer per claim
