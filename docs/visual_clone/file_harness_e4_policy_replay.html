e4_policy_replay.py

This file simulates counterfactual selection policies over every graded task in the frozen ablation notes. It joins each task's uuid order, evolution rewards and ablation VER/SR grades by uuid suffix, then replays ten policies and counts the grader queries each one spends. It runs only as a script (python e4_policy_replay.py [date], L483–L484); no other file imports it.

Diagram 3 — the decision rule inside run_policy

Diagram 3 — the whole file is a dispatch on the policy name plus two loops that stop at the first hit. P6 and P6b add a gate before any query: when plateau_fires is false both fall back to p0_pick (L156, L166) and spend 0 queries.

Amber: P1 reads the recorded VER label directly (L132), which the payload calls an oracle: a real VER check would itself cost a grader query, and P1seq is the billed variant (L138). The file states this at L408.

Red: main contains a dead placeholder line, tr = [r for r, in zip(rs, strict=False) if False] (L313), and tr is never used again; thr from L312 is the top-quartile threshold that is kept. Both sit between the tau table and the pooled tau.
