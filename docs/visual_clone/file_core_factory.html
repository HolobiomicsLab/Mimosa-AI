factory.py

Base class Factory (line 16) holds the plumbing that both code generators share: tool discovery, the single-agent prompt, folder creation and file writes. It runs while a workflow is being crafted, before the sandbox executes anything. SingleAgentFactory and WorkflowFactory inherit it and call its methods from their own craft routines.

Missing method: save_workflow_files writes the system prompt with self.get_system_prompt() (L185), but that method is not defined in this file; it exists only in sources/core/workflow_factory.py:49. SingleAgentFactory inherits this writer (sources/core/single_agent_factory.py:307) without defining get_system_prompt, so in single-agent mode the AttributeError is caught at L189-L190 and logged, and system_prompt_<uuid>.md is not written.

Why it matters: this file is the only place that turns a crafted workflow into files on disk, so the file names it writes are the names the rest of the pipeline looks for.
