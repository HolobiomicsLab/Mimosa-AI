e19b_dryrun — label-free config selection

Phase 2b asked whether richer claims and graded scores make the hybrid verifier decisive without reading a single benchmark label. The script samples five configs (two claim sets, three score ledgers), scores the 667 planned pairs under three aggregation rules, writes V5 gradient texts and judges a declared 5-group pilot with the E16 instrument. The chosen config feeds the confirmatory readout on e19b_eval; the shipped package is hybrid_verifier.
