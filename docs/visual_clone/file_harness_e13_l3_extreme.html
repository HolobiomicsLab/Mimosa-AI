e13_l3_extreme.py

The E13 study runner: eight argv-selected stages test whether claim-set structure (clusters, set attention, soft judge scores, base rates, goal conditioning) beats the linear L3 score. It runs offline on frozen caches, with zero LLM API calls. Each stage appends its arm into one shared results JSON, and the last stage writes the Markdown report.
