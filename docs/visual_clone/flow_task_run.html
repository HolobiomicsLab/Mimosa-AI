Task run flow

One task, from the command line to one scored workflow folder on disk. This page covers uv run main.py --task "..." without --learn, and the same command up to the first generation with --learn. Nothing here runs the application; every step was read from the code.

Structural note: the default template_uuid 20260512_162504_70ccefbf is not a folder in sources/workflows/ here (checked 2026-09-28). When workflow_dir holds at least one state_result.json, select_parent_workflow returns the template without checking its folder. Generation 1 is therefore recorded as evolution_kind = "mutation" against a parent that is absent, and WorkflowInfo.load_code returns "" for it.

Docs say the runner uses the SmolAgents LocalPythonExecutor with an AST allow-list (AGENTS.md, README.md line 98); WorkflowRunner.execute actually writes the script to tmp/ and starts a plain subprocess with cwd = workspace_dir and a timeout, and no AST check exists on that path.

Step 19 - which verifier runs

Diagram 2 - sources/evaluators/evaluator.py::WorkflowEvaluator.__init__ builds one verifier from config.verifier_kind. oracle - leaks gold For gold, GoldFeedbackEvaluator.evaluate first copies the workspace (make_private_copy), runs the inner hybrid, grades the copy, then writes the grader's VER/SR text as textual_gradient.txt.

Amber note: on a plain --task run, gold_feedback_task_row is unset, so resolve_task_context returns no context, nothing is graded, and the gradient stays the hybrid one; only --science_agent_bench sets the row (CsvEvaluationMode._set_gold_feedback_task).
