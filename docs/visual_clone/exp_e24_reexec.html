e24_reexec — clean-room re-execution

Do frozen workspaces still run when re-executed from a clean copy? The script copies each delivered workspace, strips generated outputs, re-runs the entry script in a pinned Python 3.10 sandbox and compares the new outputs to the frozen ones. It classifies every generation and appends resumable ledgers.
