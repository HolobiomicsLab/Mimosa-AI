e24_eval.py

This file is E24 Phase 3: the only E24 stage that reads labels (SR, VER and reward) and the only one that turns the ledgers into a verdict. It composes one score per generation — verifier-owned holdout where the group admits it, clean-room re-execution status elsewhere — then runs ten readouts from within-task pairs-correct to the cost table, and writes the report json and md. It runs by hand after phases 0 to 2: uv run python experiments_verifiers/harness/e24_eval.py L23.
