e19b_extract — extraction v2, V4 scorers, refinement

Phase 2 of E19b built the paid artifacts that the dry run and readout later used: extraction v2 (8 to 12 decisive, decidable, graded claims), V4 scorer scripts that report measured quantities, and a refinement loop that replaces dead claims. The script also re-scores the original v1 claims with V4 scorers, so the scorer change stays isolated from the claim change. It writes five resumable JSONL ledgers plus one cost ledger under a $10 cap, and it feeds e19b_dryrun and hybrid_verifier.
