grader.py

This 253-line file resolves the benchmark task row, copies the generation workspace to a private mimosa_gold_* temp dir and grades the copy with the shared grade_directory. A harness error or a run over the wall-clock cap becomes a censored excluded result, so the verifier never crashes. Its only caller is GoldFeedbackEvaluator.
