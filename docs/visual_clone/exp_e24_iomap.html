e24_iomap — Phase 0, I/O mapping and gates

Can one LLM call per group map each workspace's entry script, train file, test file, output file and metric well enough for the verifier to re-execute it? This script makes that map, then checks four gates by deterministic file reads on the frozen snapshots. Five of nineteen groups admit the verifier-owned holdout (Phase 2).
