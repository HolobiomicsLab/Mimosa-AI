base.py

This file holds BaseEvaluator, the shared parent of every evaluator: it validates the config, builds the judge LLMConfig, reads one workflow folder and calls the judge model. It also holds extract_json_payload and the five evaluator exception classes. It runs when an evaluator subclass is built and whenever that subclass reads a run or asks the judge for JSON.
