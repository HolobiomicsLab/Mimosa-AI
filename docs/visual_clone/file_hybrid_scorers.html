scorers.py

This file writes the prompt that asks for one deterministic scoring script per claim, screens the returned code, wraps it in a launcher and parses the single JSON line it prints. It is a pure text builder and parser: no file and no subprocess runs inside it. layers.py calls it in the scorer build loop; package context is on mod_evaluators_hybrid_verifier.html.

Why it matters: the same script text grades every workspace, so the measured quantity stays stable across generations.

Real deviation from the harness port: the harness passed the workspace and claim as argv[1] and argv[2]; the repo runner passes no argv, so build_launcher injects WORKSPACE_ROOT and CLAIM as module constants (L11-14, L257-263). A harness script and a repo scorer script are therefore not interchangeable.
