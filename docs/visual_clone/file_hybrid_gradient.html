gradient.py

This file writes the two texts of one generation: the textual gradient the mutator reads, and the human-readable evaluation.txt. It runs at the end of HybridVerifierEvaluator.evaluate, after the reward is known, and it only formats measured facts. The package view is on mod_evaluators_hybrid_verifier.html and the wider flow on flow_verification.html.
