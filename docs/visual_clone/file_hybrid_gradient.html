gradient.py

This file writes two texts: the textual gradient the mutator reads, and the human-readable evaluation.txt report. It runs at the end of HybridVerifierEvaluator.evaluate, after the reward is known, and it is pure formatting of measured facts. The verifier as a whole is on mod_evaluators_hybrid_verifier.html and flow_verification.html.
