e16_gradient_audit.py

This file is the E16 instrument harness: seven --stage sub-runs join the on-disk evolution gradients to their labels and gold files, validate one LLM judge against mutated control gradients, then score every gradient against what its task's grader measures. It runs from the command line as uv run python experiments_verifiers/harness/e16_gradient_audit.py --stage <name> and writes its numbers under experiments_verifiers/results/. The later duel experiments (E17, E18, E19b, E19c, E24) import it as their validated judge instrument.

Diagram 1 — 11 boxes. Every stage function is reached from main (L1553–L1567), and the three helpers _llm, judge_messages and _compute_gates are shared by the stages that call them. stage_report writes both report files through _write_md (L1270, writing at L1545).
