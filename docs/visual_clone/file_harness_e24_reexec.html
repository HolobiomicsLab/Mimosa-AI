e24_reexec.py

This file re-executes every frozen E24 generation in a clean room and labels the outcome: copy the snapshot, strip generated outputs, run the mapped entry script in a pinned sandbox, compare the new outputs with the frozen ones. It runs by hand, in stages, from the command line; a 600 s wall cap and a process-group kill guard each run. The label it assigns (clean_recover, divergent, crash, timeout, no_entry_script) is pre-registered in the docstring L15–L24.
