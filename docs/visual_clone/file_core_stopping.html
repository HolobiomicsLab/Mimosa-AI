stopping.py

Holds StopController (line 36), the session decision to stop the evolution loop; the folder map is area_sources_core.html. It replaces the absolute learned_score_threshold rule with a champion plateau for the pairwise verifiers hybrid and policy_bt. EvolutionEngine.start_workflow_evolution builds one controller per task, feeds it one observe() per generation, and asks should_stop() after each one (mod_core_evolution_engine.html maps that engine).

The controller is pure: the arguments carry every value, so the same configuration replays identically and tests build it without an engine; the constructor defaults mirror the Config defaults (min_iter 6, patience 3, threshold 0.9, max_iter 16), but the engine always passes all five explicitly.

Mismatch: the evaluator sets self.verifier_kind to the raw config string (sources/evaluators/evaluator.py:121) while an unlisted kind falls through to HybridVerifierEvaluator (sources/evaluators/evaluator.py:117-119); config.verifier_kind is not validated on load (config.py:594). A JSON config with, for example, verifier_kind = "generic" therefore gets the hybrid win-rate reward together with threshold mode, which is the stop rule the module exists to replace.
