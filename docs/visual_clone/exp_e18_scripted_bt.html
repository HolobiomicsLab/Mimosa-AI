e18_scripted_bt — execution-grounded Bradley–Terry

This experiment replaced E15 preference judging with generated comparison code: an LLM wrote a deterministic script per artifact pair, and the script output picked the winner. The question was whether that execution-grounded ranking beats preference judging and the recorded reward within a task.
