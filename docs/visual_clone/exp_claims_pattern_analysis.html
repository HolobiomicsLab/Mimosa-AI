claims_pattern_analysis — hidden structure in the claim vocabulary

This experiment asked whether the verifier's claim text carries hidden structure: functional families, a shared vocabulary, and task families by suite overlap. The script embeds every unique claim name, picks k by silhouette, clusters tasks by Jaccard overlap, and splits claim pass rates by benchmark SR. Answer: 13 soft families and a cophenetic 0.97 task tree exist, but SR success tracks generic structural claims, while the computation family fails in both outcome groups.

Why it matters: the pass-rate gap between outcome groups is +4 to +12 points on script, format, data and model families, but the computation family C12 stays near 67–69% in both groups, so passing computation claims is not what separates SR-winning tasks.

Red: the duplicated suites are a real defect, not a modelling artefact — capsule_bio_eventrelated_analyze_bio_eventrelated_analyze and plot_phonon_dos_dft_plot_phonon_dos share one 53-claim ECG suite at J = 0.000 (L3709–3711). This script measured it; it does not explain it.
