e9_deployment — does learned importance beat the recorded reward?

With the contamination of exp_e8_blast_radius.html removed, this experiment scores every asb_full_iterative_1 generation with L3 and ships the best one per task, checking the recorded SR. L3 weights are trained on the other campaigns only, so the comparison is an honest cross-campaign transfer. Folder context: data_experiments.html.

Design — hypothesis, inputs, stages, artifacts

Diagram 1 — 11 boxes. Dashed grey = frozen sane inputs, mint pills = functions in e9_deployment.py, cyan = the written artifacts. load_sane (L46) drops rows with SR or claims null and maps claim status through SCORE_MAP (L39); manifest_index (L63) groups manifest rows and mrow_cat (L72) labels them carried, contaminated or recovered. l3_feats (L90) builds the pass-weighted centroid, l3b_feats (L98) adds the fail centroid and counts, fit_score (L142) selects C with select_C_inner (L120) and fits the logistic. replay (L159) ships the argmax per task, breaking ties on the latest uuid_long, which manifest_index supplies (that edge is named here, not drawn). The sensitivity path re-runs only the reward baseline and the task count over the recovered rows (pseudo_scores L302).
