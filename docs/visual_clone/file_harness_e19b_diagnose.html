e19b_diagnose.py

This script counts why the E19 v1 gradient feedback stopped improving. It reads the frozen E19 v1 judge corpus, claim and score ledgers and the gradient transcripts, and it makes zero LLM calls. It writes one diagnosis JSON with counted themes, failure modes, rank correlations and six pre-registered hypotheses.
