## Acknowledgements

Mimosa-AI builds on:

- [smolagents](https://github.com/huggingface/smolagents) — agent runtime.
- [LangGraph](https://github.com/langchain-ai/langgraph) — shared agent state.
- [LiteLLM](https://github.com/BerriAI/litellm) — multi-provider LLM abstraction.
- [Model Context Protocol](https://modelcontextprotocol.io/) — tool interface.
- [Langfuse](https://langfuse.com/) — observability.

Companion projects from the same lab:

- [Toolomics](https://github.com/HolobiomicsLab/toolomics) — MCP tool host.
- [Perspicacité](https://github.com/HolobiomicsLab/Perspicacite-AI) — literature grounding.
